Research notes (November 2026)#

This is a summary of the research behind the product and technical choices. Items marked ⚠ could not be fully verified from primary sources at the time of writing. Treat them as starting points, and check versions and tags yourself.

2. Answer rubric#

Sources: STAR and CARL (Context, Action, Result, Learning), US OPM structured-interview guidance (1–5 behavioural anchors, the same questions and scale for every candidate), Google re:Work structured interviewing, and Amazon's Leadership Principles (STAR, "I" not "we", data).

The evaluator scores structure, relevance, specificity (own actions, concrete detail), impact (measurable result) and communication (concise, confident). It adds technical depth for technical and system-design questions. Anchors are defined at 1, 3 and 5. Delivery is measured in code, not by the model:

  • Conversational pace is roughly 130–170 WPM (Yoodli); hints trigger above 180 or below 95.
  • Filler words become noticeable above about 3–8 per 100 words (Big Interview); hint above 6, communication capped above 8.
  • Behavioural answers: about 1–2 minutes. The default time limit is 150 s.

Debrief-style read per answer: overall ≥ 4.5 with no dimension below 4 → strong; ≥ 3.5 → lean hire; ≥ 2.5 → lean no; below that → no.

3. Speech-to-text on Windows with an RTX 4080#

  • faster-whisper 1.2.1 with CTranslate2 4.8.x (Windows wheels for current Python versions). large-v3-turbo in float16 uses about 2.5 GB of VRAM. distil-large-v3.5 is a faster English-only alternative.
  • CUDA: recent CTranslate2 releases make cuDNN optional, so cuBLAS 12 is enough. nvidia-cublas-cu12==12.9.2.10 is the newest release with a Windows wheel (checked on PyPI). The app adds the pip-installed NVIDIA bin folders to the DLL search path and PATH at runtime.
  • Streaming: utterances are cut with VAD and re-transcribed about once a second for partial text (the pattern used by WhisperLive and SimulStreaming-style servers, simplified). Finals use beam search with Silero VAD.
  • Filler words: Whisper tends to drop "um" and "uh". In practice mode the app primes Whisper with a disfluent prompt (best effort ⚠), so filler counts may still read low.
  • Alternative: NVIDIA Parakeet TDT 0.6B v3 via onnx-asr runs on Windows without NeMo ⚠. It isn't wired in yet; it's a candidate engine.

4. Ollama (current release line 0.40.x ⚠)#

  • /api/chat with "format": <JSON schema> gives structured output. The app also validates and repairs.
  • "think": false disables reasoning on thinking models (Qwen3, Gemma 4), which is better for JSON and latency.
  • /api/embed → {"embeddings": [[…]]}. Used for semantic meeting search.
  • Set the context window explicitly. Ollama's default on GPUs under 24 GB is small and silently truncates long inputs. The app sends num_ctx: 16384.
  • VRAM tips: OLLAMA_FLASH_ATTENTION=1 and OLLAMA_KV_CACHE_TYPE=q8_0 (run scripts\setup.ps1 -TuneOllama).
  • Models for 16 GB:
  • Default: qwen3:14b, a reliable JSON follower (about 12 GB loaded).
  • Newer options to try: qwen3.5:9b and gemma4:12b ⚠ (verify the tags with ollama list / ollama.com).
  • Avoid dense 27B+ models on 16 GB: they spill to the CPU.
  • Embeddings: nomic-embed-text (default), or qwen3-embedding:0.6b / embeddinggemma ⚠.

5. Browser audio#

  • getDisplayMedia must be called from a click and must request video. To capture meeting audio, share the meeting tab with "Share tab audio" (browser-based calls), or share the entire screen with "Share system audio" for desktop Zoom and Teams on Windows. If the user unticks audio there's no error, so the app checks getAudioTracks().length.
  • new AudioContext({sampleRate: 16000}) lets Chrome and Edge resample. An AudioWorklet converts to 16-bit PCM in ~100 ms frames for the WebSocket.
  • Web Speech API: Chrome's recognition is server-based (Google) and Edge uses Azure. That's why local Whisper is the default and the browser path is only a fallback, with a notice.

6. Consent#

See RESPONSIBLE_USE.md. In summary: one-party consent is the US federal rule; about a dozen states require all parties' consent; GDPR needs a lawful basis plus notice. Practices adopted: a consent gate per meeting, a visible recording indicator, a copyable disclosure line, no audio retention, delete-last-N-minutes, a retention timer, and no voiceprints.

7. Claude API (optional backend)#

  • Default model: claude-opus-5-5, configurable in Settings (claude-sonnet-5-5 / claude-haiku-5-5 cost less).
  • Structured outputs via output_config.format (JSON schema). Depth is set with output_config.effort (medium for analysis, low for fast tasks); thinking stays adaptive.
  • temperature is not sent: current API versions reject sampling parameters.
  • Server-side refusal fallback (fallbacks: "default", beta server-side-fallback-2026-07-01) is enabled on supported models.
  • Prompt caching is applied to system prompts. Spend is estimated from token usage and capped by a monthly budget.
